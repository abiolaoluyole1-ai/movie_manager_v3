SETTINGS

Local application

General

Basic behaviour for how Movie Manager builds your catalogue.

Minimum movie duration

Movie Manager only keeps full-length movies (60+ minutes).

Maintain target automatically

If you remove a movie, Movie Manager can look for a replacement on its own.

Count only downloadable movies toward target

When on, your target only counts movies that are ready or already downloaded, not just found.

Downloads

Where movies are saved and how many download at once.

Simultaneous downloads

How many movies Movie Manager can download at the same time. A finished movie's slot is filled immediately by the next one.

Minimum free disk space (GB)

Downloads pause automatically -- without touching what's already saved -- when free space on the download drive falls below this.

Download folder

Completed files are placed inside language folders such as Yoruba, Igbo and Hausa.

Sources

Where Movie Manager looks for movies.

YouTube connection

Your private key stays inside the local .env file and is never shown here.
